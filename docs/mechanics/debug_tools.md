# Debug tools

Dev-only tooling, ported from `../first`. Gameplay never depends on any of it.

**Scripts:** `debug/tuning/tuning_panel.gd` (+ `.tscn`), `tuning_fields.gd`, `tuning_preview.gd`, `debug/tuning/visuals/tuning_visual.gd` (diagram base), `tuning_visuals.gd` (diagram registry); `menus/pause_menu.gd` (+ `.tscn`), `menus/game_settings.gd`; `debug/time_scale/time_scale_control.gd` (autoload `DebugTimeScale`). Playtest log: `docs/playtest_log.md`.

## How it works
- **Pause menu** (`pause`, Esc): pauses the tree; Resume, Options (volume, fullscreen, saved to `user://settings.cfg` by `GameSettings`), Tuning (debug builds only), Quit. Every level instances it.
- **Tuning panel:** each tab in `TuningPanel.TABS` lists stats classes; every `.tres` in `tuning/` of those classes is shown. `TuningFields` reflects on the exported properties: each `@export_group` is a foldable section, each property a row (slider and number box, checkbox, colour button, or one box per float-array element). `@export_range` sets the slider range; otherwise it spans 0 to three times the value (`_db` names get a decibel range). Edits apply live and emit `changed`. "Save tab to .tres" writes the current tab back to disk; "Reset tab" reloads from disk. The `##` doc comment above each export is its tooltip and its description in the preview column.
- **Diagrams (tuning visuals):** hovering a row shows an animated diagram drawn from the live values, when one exists. A diagram extends `TuningVisual`, declares `static func covers() -> Dictionary` (stats class to property names) and overrides `setup()` and `paint()`; list it in `TuningVisuals.SCRIPTS`. Shared style and helpers (scale constants, `w()` top-down metres to pixels, `iso()`, arrows, rings, graphs) live in the base. None exist yet.
- **Slow time:** `debug_time_slower` / `debug_time_faster` (`[`, `]`) step `Engine.time_scale` through `TimeScaleStats.steps` (Debug tab) from the listed speed nearest the current one; `debug_time_reset` (`\`) returns to 1. A label at the top shows the speed while it isn't 1. Debug builds only. Views that should keep real speed divide their `delta` by `Engine.time_scale` (the camera rig does).
- **Map debug:** `debug_show_map_grid` (8) shows impassable cells and selected units' paths (`pathing.md`).
- **Day and night:** `debug_day_night` (N) swaps the atoll's light preset (`debug/day_night/day_night_toggle.gd`; `heightmap.md`, "Terrain shadow").
- **Night check:** `debug/night_check/night_check.gd`, run with a window: `godot --resolution 1600x900 --script res://debug/night_check/night_check.gd -- <folder>`. Takes fixed shots of the atoll by night and day with its own test units (RTS view on lit ground, shadowed ground and sea; a ridge skyline; cockpit height; bird's-eye) and prints each unit's luminance contrast against what is behind it (mean ratio over its pixels, with and without it; the blip in the bird's-eye view). It stops the simulation, sea and clouds, and saves the shots and `report.csv`. Day is the baseline; shots below its share `FLAG_BELOW` per unit are listed.
- The Audio tab holds the sound and effect stats (`audio.md`).

## Tuning panel look
Built from `docs/plans/tuning_panel_redesign.md`. The panel has its own `Theme` (`debug/tuning/tuning_theme.tres`, generated by `TuningThemeBuilder`; regenerate with `godot --headless --script res://debug/tuning/build_tuning_theme.gd`), set on its root so the HUD theme is untouched. It uses the tool type scale in `UiTokens` (`TEXT_TOOL*`, 18/20/24 px; `TOOL_ROW_UNITS` row height): IBM Plex Sans (`assets/fonts/`) for labels, figures, descriptions and buttons; Anybody wide for the titles. The panel takes a share of the viewport (`SCREEN_SHARE`); rows are a `TuningRow` panel with label, slider and number box as stretch-ratio columns (`TuningFields`), the row in the preview is marked `TuningRowActive`. No per-node overrides: scenes and code use the `Tuning*` variations.

## Settled
- Tuning panel and playtest log carried over unchanged in behaviour from `../first`. Mouse capture and mouse sensitivity were dropped (an RTS keeps the cursor).
- The panel's size never depends on what is hovered: the preview's description scrolls inside a fixed area and its title clips with an ellipsis. Otherwise a long doc comment grows the panel and the pause menu's `CenterContainer` re-centres it, so the panel jumps as the mouse moves.

## Tried and passed on
- Keeping the game window from taking focus on launch (`WINDOW_FLAG_NO_FOCUS` set at runtime, the `display/window/size/no_focus` setting, `open -g`, `open -j`): in each case Godot 4.7.2 still became the frontmost app on macOS. A script handing focus back afterwards was also dropped: the window still flashes to the front. No cheap fix found.

## Known issues
- `hud_scale` scaling of the menus (in `../first`) isn't ported: there is no HUD stats class yet.
